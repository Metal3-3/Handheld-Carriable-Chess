# Handheld-Carriable-Chess
ESP32 based handheld carriable chess
<img width="657" height="576" alt="image" src="https://github.com/user-attachments/assets/b43be7fc-f3ad-44ac-9a67-67891d824027" />

It uses a cheap yellow display esp32 (ESP32-2432S028R) 18650 2800 Mah 7.4v battery and thats pretty much it.

# Code info
The og code was made by Sergey Urusov for the arduino mega but it has been modified to be used with cyd (uses lovyangfx instead)
(https://projecthub.arduino.cc/Sergey_Urusov/794c19d4-03bd-4a71-b669-eb8fcbe9ce7b)
